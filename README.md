### 🔧 What I Work On

Since 2023 I've been at Synapticon, which makes SOMANET servo drives and motion control for robotics and automation. My part of it:

- **[OBLAC Drives](https://www.synapticon.com/en/products/oblac-drives)**, the app customers use to configure, tune and commission SOMANET drives. An Angular and NgRx front end on a TypeScript client library that talks to the drives through Motion Master.
- **Production software**, the stations our production line uses to assemble and test drives before they ship. Mostly Python: PySide6 desktop apps and a Django back end.
- **[Motion Master client examples](https://github.com/synapticon/motion-master-client-examples)**, TypeScript and JavaScript examples for configuring and controlling SOMANET drives from your own code.

Most of this lives in private repositories, so not much of it shows up here.
